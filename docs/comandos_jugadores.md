# Comandos de Jugadores 🇪🇸

### Insurgency Weapons — Tienda de armas

Abre el menú de compra de armas usando el dinero acumulado en el mapa.

```
\buy
```

> El dinero se gana por puntaje. Saldo inicial: 5000.

### RockTheVote — Cambiar mapa

| Comando (en el chat) | Descripción |
|---|---|
| `rtv` | Vota para cambiar el mapa actual |
| `nominate <mapa>` | Nomina un mapa para la votación |

> Espera 30 segundos después de unirte antes de poder votar.

### Lt-Parachute — Paracaídas

- **Abrir:** mantén presionado **E** (usar) mientras caes
- **Cerrar:** suelta **E**

### CLevels — Sistema de XP y Niveles

Gana XP completando mapas y eliminando enemigos. Usa los puntos para mejorar tu personaje.

| Comando (en el chat) | Descripción |
|---|---|
| `/menu` | Menú principal |
| `/selectskills` | Elige tus habilidades |
| `/resetskills` | Reinicia las habilidades para redistribuirlas |
| `/skillsinfo` | Detalles de todas las habilidades |
| `/selectspecials` | Elige habilidades especiales (requiere medallas) |
| `/resetspecials` | Reinicia habilidades especiales |
| `/specialsinfo` | Detalles de las habilidades especiales |
| `/handicaps` | Activa hándicaps para ganar más XP |
| `/handicapsinfo` | Detalles de todos los hándicaps |
| `/character` | Resumen de tu personaje |
| `/xpgain` | XP ganado en el mapa actual |
| `/achievements` | Menú de logros |

#### Habilidades (Skills)

| # | Habilidad | Efecto |
|---|---|---|
| 1 | Strength | Mayor HP inicial |
| 2 | Superior Armor | Mayor armadura inicial |
| 3 | Regeneration | Regenera HP con el tiempo |
| 4 | Nano Armor | Regenera armadura con el tiempo |
| 5 | Ammo Reincarnation | Restaura munición automáticamente |
| 6 | Anti-Gravity Device | Reduce la gravedad — salta más alto (mantén Jump) |
| 7 | Awareness | Mejora levemente otras habilidades |
| 8 | Team Power | Apoya a compañeros cercanos con HP y AP |
| 9 | Block Attack | Probabilidad de bloquear ataques por completo |
| 10 | Medals | Mejora todas las habilidades + bono de XP; necesario para Special Skills |

#### Habilidades Especiales (Special Skills)

Solo disponibles con medallas (1 medalla = 1 special point).

| # | Habilidad Especial | Efecto |
|---|---|---|
| 1 | Starting Attack | Al revivir/reaparecer, daña a enemigos cercanos |
| 2 | Portable Dispencer | Duplica toda la munición regenerada |
| 3 | Ubercharge | Aumenta la capacidad máxima de las habilidades básicas |
| 4 | Quick Heal | Munición extra del Medkit cada pocos segundos |
| 5 | Demoman | Probabilidad de obtener granadas del M16 |
| 6 | Practice Shot | Probabilidad de disparar sin consumir munición |
| 7 | BioElectric | Aumenta la capacidad máxima del Shock Rifle |
| 8 | Medical Emergency | Cura aliados a distancia con el Medkit (ataque terciario) |
| 9 | Red Cross | Aumenta la capacidad máxima del Medkit |

#### Hándicaps

Hacen el juego más difícil a cambio de bono de XP. Solo se pueden activar al inicio del mapa.

| # | Hándicap | Efecto | Bono XP |
|---|---|---|---|
| 1 | Medical Phobia | No puede ser curado (excepto por regeneración) | +22% |
| 2 | Obsolete Technology | No puede reparar la armadura (excepto Nano Armor) | +27% |
| 3 | Nitrogen Blood | No puede ser revivido; siempre explota al morir | +13% |
| 4 | Karmic Retribution | Todo daño recibido también envenena | +18% |
| 5 | Realism | Oculta el HUD (suit) | +22% |
| 6 | Big Explosion | Las explosiones causan mucho más daño | +18% |
| 7 | Limited Equipment | Restringido a solo un arma | +18% |
| 8 | Dead Weight | Gravedad aumentada — más difícil saltar | +18% |
| 9 | Lacking Help | Desactiva parcialmente Medals y Special Skills | +13% |
| 10 | Dirty Mag | La munición restante en el cargador se pierde al recargar | +22% |
| 11 | Lost Bullets | Restringido a solo un cargador por arma | +18% |
| 12 | Weak Restart | Al revivir/reaparecer, comienza con 25 HP y 0 AP | +31% |
| 13 | Dangerous Waters | Ahogamiento instantáneo bajo el agua | +13% |
| 14 | Bleeding View | Efecto de concusión que empeora con menos HP | +18% |
| 15 | Health Crisis | Capacidad del Medkit reducida a la mitad | +15% |
