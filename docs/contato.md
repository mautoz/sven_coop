# Reporte / Contato

Use os links abaixo para reportar problemas, enviar sugestões ou fazer denúncias sobre o servidor.

Cada link abre uma issue no GitHub com o tipo já classificado. Não precisa de conta especial — basta ter acesso ao GitHub.

---

## :bug: Bug / Problema técnico

Servidor caiu, mapa travado, plugin com erro, crash ao entrar, etc.

Antes de reportar, consulte a [página de ajuda do servidor](https://fastdl.mtavaresozaki.com.br/ajuda/) — pode haver informações sobre o problema ou como contorná-lo.

[Reportar bug :material-arrow-right:](https://github.com/mautoz/sven_coop/issues/new?labels=bug&title=Bug%3A+&body=%23%23+Descri%C3%A7%C3%A3o%0A%0A%23%23+Como+reproduzir%0A%0A%23%23+Mapa%2FPlugin+afetado){ .md-button .md-button--primary target="_blank" }

---

## :bulb: Sugestão

Novo mapa, ajuste de plugin, ideia de campanha, melhoria de configuração.

[Enviar sugestão :material-arrow-right:](https://github.com/mautoz/sven_coop/issues/new?labels=enhancement&title=Sugest%C3%A3o%3A+&body=%23%23+Sugest%C3%A3o%0A%0A%23%23+Motivo%2FBenef%C3%ADcio){ .md-button target="_blank" }
